# Автоматическое тестирование функций (Практика Т118)

Этот проект представляет собой практическое задание по написанию и запуску юнит-тестов (автотестов) для набора Python-функций.

## Структура проекта

* **`quality.py`** — модуль, содержащий основные функции (`classify_score`, `normalize_status`, `apply_result`, `summarize`, `run_tests`), в которых изначально были заложены дефекты[cite: 1]. После отладки функции были исправлены.
* **`test_quality.py`** — модуль с набором тестов (`assert`) для каждой функции, а также пользовательским запускателем тестов (`run_tests`).
* **`checks.md`** — отчёт с описанием входных данных, ожиданий, найденных дефектов и результатов регрессионного тестирования[cite: 4].

## Системные требования

* **Python 3.x** (при запуске **не** используйте оптимизирующий флаг `-О`)[cite: 1].

## Как запустить тесты

Откройте терминал в папке с проектом и выполните команду[cite: 1]:

```bash
python test_quality.py
